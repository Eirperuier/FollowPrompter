# 随声提词（FollowPrompter）

iPad 提词器，**跟读模式下文字会跟着你的语速滚动**：读得快就走得快，停下来就停，跳读或重读能自动找回位置。

## 安装到 iPad
1. `open FollowPrompter.xcodeproj`（如修改了 project.yml，先运行 `xcodegen generate`）
2. 选中 FollowPrompter target › Signing & Capabilities › Team 选择你的 Apple ID
3. iPad 用数据线连接 Mac（或同一 Wi‑Fi 下配对），在 Xcode 顶部选中你的 iPad，⌘R 运行
4. 首次运行需在 iPad「设置 › 隐私与安全性 › 开发者模式」开启，并在「设置 › 通用 › VPN与设备管理」信任开发者
5. 用免费 Apple ID 签名的应用 7 天后需重新从 Xcode 安装一次；付费开发者账号有效期为一年

## 三种模式
- **跟读**：实时语音识别 + 稿件比对，按读到的位置滚动（iPadOS 26 起完全离线识别）
- **匀速**：固定速度滚动，可调速度
- **手动**：手指拖动

## 操作
- 单击：显示/隐藏控制栏；双击某个字：从那里开始；拖动：手动调整位置
- 外接键盘或翻页笔：空格 开始/暂停，↑↓←→ / PageUp/PageDown 前后移动，Esc 退出
- 文字设置：字号、行距、边距、阅读线位置、已读变暗、水平镜像/垂直翻转（用于提词器分光玻璃）、识别语言

## iPhone 遥控器 / 重读本句
（安卓手机见下面的「安卓遥控器」）
同一个 App 装到 iPhone 上，打开就是「遥控器」页（另一个标签页是稿件库，iPhone 也能直接当提词器用）。
- iPad 打开任意稿件的提词页面后，iPhone 会自动发现并连接（蓝牙 / 点对点 Wi‑Fi，不需要联网；首次会弹出"本地网络"权限，请允许）
- **重读本句**：回到当前句开头；刚回到句首时再按一次，会再退一句（连按逐句后退）
- **重读本段**：回到当前段开头；另有 上一句 / 下一句 / 开始暂停 / 回到开头，匀速模式下可调快慢
- 跟读模式重读时不用暂停，直接重新开口即可，提词会等你；匀速模式重读时会自动暂停并重新倒数
- 遥控器上能看到当前句、下一句、进度、用时和重读次数；iPad 上会闪一下红色"重读本句"提示
- iPad 自身：底部有"重读本句"按钮，外接键盘按 Delete 也可以
- iPhone 遥控页面会保持亮屏；锁屏或切到后台会断开，回来后自动重连

## 安卓遥控器
`android/` 目录是独立的安卓 App「随声提词遥控器」（Kotlin + Jetpack Compose，Android 8.0 及以上），功能和 iPhone 遥控器一致：重读本句 / 本段、上一句 / 下一句、开始暂停、回到开头、匀速调速，显示当前句、下一句、进度和重读次数。
- 手机和 iPad 连**同一个 Wi‑Fi**，iPad 打开提词页面后安卓 App 会自动发现（mDNS 服务 `_fpremote._tcp`）
- 第一次连接输入 iPad 上的 4 位**配对码**：提词页底部的手机图标 → 遥控器面板（也能看到已连接的设备、更换配对码）。配对码会被记住，之后自动连接、断线自动重连
- 有些公司 / 酒店 Wi‑Fi 屏蔽设备发现，可以在 App 里「手动输入地址」（遥控器面板里显示，形如 `192.168.1.5:52819`）
- **音量键遥控**（默认开启）：音量下 = 重读本句，音量上 = 开始 / 暂停，不看屏幕也能按
- 录制时保持亮屏；切到后台会断开，回来自动重连

构建（需要 JDK 17 和 Android SDK）：
```bash
cd android
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # 需要 ~/.android/followprompter-release.properties 里的签名配置
```

协议（iPad 端 `Remote/LANRemoteServer.swift`）：TCP，一行一条 JSON。遥控器先发 `{"type":"hello","name":…,"code":"1234"}`，之后发 `{"type":"command","command":"rereadSentence"}`，每 3 秒 `{"type":"ping"}`；iPad 回 `welcome` / `denied`、推送 `{"type":"status","status":{…}}`、回 `pong`。

## 飞书同步
稿件可以关联一篇飞书云文档或知识库页面，以飞书上的内容为准。

**连接飞书（一次性，做法参考飞书官方 lark-cli）**：稿件列表「···」→「飞书同步」→「连接飞书」，App 会显示二维码和链接，在飞书里确认两次：
1. 自动创建一个只属于你的应用（不用去开发者后台）
2. 授权它以你的身份读取文档（你能打开的文档都能同步，不用逐篇"添加文档应用"）

授权会自动续期；长时间没用导致过期时，按提示重新扫码授权即可。也可以在「高级」里改用自己在开发者后台创建的应用。

**使用**：
- 稿件列表右上角「+」→「从飞书选择文档…」：顶部搜索你能访问的所有云文档和知识库；首页「最近打开」列出你能看到的所有文档，包括**别人共享给你的**和知识库里的，按你打开的时间排序，别人的文档会标出所有者（开放平台没有「与我共享」列表接口，这里用空关键词搜索 + 按打开时间排序实现，再并入「我的空间」和「我的文档库」，新建后还没打开过的也不会漏）；也可以按「我的空间」「知识库」逐层浏览，点一下就导入。已导入过的会标"已导入"，再点直接打开，不会重复导入。右上角也可以粘贴链接导入
- 已有稿件可在编辑页「···」→「关联飞书文档…」，用同样的界面选择
- 自动拉取最新版本：打开 App / 回到前台、打开这篇稿件、点「开始提词」前（最多等 6 秒，失败就用上次同步的内容）；列表下拉也能手动刷新
- 同步的是纯文本：格式会去掉，图片 / 附件的占位文字（如 image.png）也会过滤掉；iPad 上的本地修改会在下次同步时被覆盖

## 识别语言
文字设置 →「识别语言」默认「自动（跟随稿件）」：按稿件文字判断朗读语言（有假名为日文；中英混排按念出来的时长比较，以占多数的为准；简繁体分别对应普通话 / 國語）。粤语稿件的文字和普通话分不出来，需要手动选「粵語」。提词页右上角的引擎标签会显示当前识别语言。

## 识别引擎
文字设置 →「识别引擎」：
- **自动（推荐）**：iPadOS 26 及以上使用新版语音识别（SpeechAnalyzer）。专为长时间连续说话设计，完全离线，没有一分钟上限、不用断开重连；先给低延迟的草稿结果，再给确认结果。每种语言第一次用时系统会下载一次语音模型：进入提词页会自动开始下载并显示进度，也可以在文字设置的「识别模型」一行提前点「下载」（两处进度同步，不会重复下载）。系统低于 26 或语言不支持时自动用旧版
- **旧版**：SFSpeechRecognizer，设备支持时离线识别，否则联网；用来对比效果，或新版有问题时切回去
- 提词页右上角会显示当前用的是哪个引擎；新版启动失败会自动退回旧版
- **稿件词汇提示**：开始前会从稿子里挑出英文词、数字、重复出现的专有名词（如"随声提词"、"提词器"，系统词典里没有的词也能拼出来），告诉识别器优先识别成这些词

Mac 上用 TTS 朗读 50 秒稿件实测（新版引擎 + 真实跟读逻辑）：位置延迟中位数 0.53 秒、P90 0.94 秒；识别准确率 96.7%；没有一次往回跳。

## 跟读原理
`Tracking/` 目录：把识别结果末尾约 12 个字和稿件做局部序列比对。
字相同得分最高，读音相同（模糊拼音：不分平翘舌、前后鼻音、n/l）次之，所以同音错字、口头禅、漏字都能容忍。
向前移动代价很低，往回跳需要很强的匹配才会发生，避免抖动。滚动用指数缓动平滑过渡，读到一行中间也会按比例连续上移。

调试参数（Debug 版）：`-openIndex N` 打开第 N 篇稿件，`-showSettings` 打开文字设置，`-settingsBottom` 滚到跟读设置，`-fakeModelDownload` 模拟模型下载（模拟器不支持新版识别，用来预览下载界面），`-demoChunks` 模拟识别结果分批到达。

运行测试：`xcodebuild test -scheme FollowPrompter -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5)'`
